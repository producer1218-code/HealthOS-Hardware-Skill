# Contributing

Open an issue describing the metric or device, its primary documentation, units and access conditions before a large integration. Pull requests should include synthetic fixtures and tests that cover malformed records, missing days and device changes. Document any new algorithm's source, population, outcome, measurement window and failure modes. Separate published evidence from engineering assumptions.

Do not commit user exports, credentials, location history, medical records, partner SDK binaries or copyrighted paper PDFs. Vendor names in the matrix describe interoperability research and do not imply endorsement.
