HealthOS Skill 是什么？

开源的个人健康 Agent Skill 与配套 Python 运行时。帮助你把已有健康硬件的允许记录交给自己的 Agent，插入自己的 LLM，形成有证据的定期健康观察报告，并根据明确反馈更新可检查记忆。旧名 HealthOS Open；仓库和运行时仍为 healthos-open。

常见问题 / HealthOS Skill FAQ

可以使用自己的 LLM 吗？

可以，支持 Chat Completions JSON 和报告模型插件；外部分享默认关闭。密钥在用户私人部署环境配置。Skill 本身不调用模型或启动同步。

Fitbit 数据怎样接给 Agent？

先检查访问资格。没有 Google API 权限时用官方导出；已获资格时可试只读接口。项目目前暂停新用户接入，拥有手环不等于拥有 API 资格。

报告经过医院或专家验证吗？

公开研究和指南支持测量条件与一般健康行动；个人基线参数是工程假设，尚无临床验证、专家签字或健康效果研究。

为什么它会越来越懂用户？

记录积累形成自己的基线，用户自述和反馈更新档案、暂停不适合的行动。不会从传感器推断心理画像，不把感受变化当作效果证明。

安装 Skill 就会定期推送吗？

不会。Skill 是指引包；监控和推送需要自己的运行时、常驻进程、数据与投递授权。
