# Expert review worksheet — unsigned

No clinician, psychologist or hospital has endorsed this repository. Use this worksheet when engaging independent reviewers. Keep names and signatures outside a public repository unless they consent.

| Review item | Questions to answer | Status |
| --- | --- | --- |
| Intended use | Wellness reflection, screening or medical management? Which jurisdiction? | Pending |
| Population | Age, health conditions, exclusions and accessibility? | Pending |
| Measurement | Reference method, wear conditions, bias and failure cases? | Pending |
| Signal | Distinguish PPG pulse intervals from ECG R-R intervals; document signal quality? | Pending |
| Algorithm | Are windows, missingness and thresholds justified for each endpoint? | Pending |
| Wording | Could a user mistake a trend for a diagnosis or an all-clear? | Pending |
| Escalation | What should happen after severe symptoms, alarming self-report or a confirmed abnormal reference test? | Pending |
| Psychology | Could reminders create anxiety or compulsive checking? Are mute and opt-out clear? | Pending |
| Equity | Have device fit, skin tone, age, gender and socioeconomic constraints been tested? | Pending |
| Privacy | Are consent, access, retention, deletion and data-sharing practices appropriate? | Pending |

Review evidence should include protocol version, date, reviewer specialty, comments, changes requested and final decision. A reviewer should approve a **specific claim and version**, not the project in general.
